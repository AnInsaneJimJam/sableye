# Documentation

Project reference documents live here. The Next.js documentation website lives in `../docs-site/`.

Start the website from this directory:

```sh
bun run dev
```

Open **http://localhost:3001/docs**. The command forwards to the website's existing pnpm script. Install dependencies with `pnpm install` at the repository root if needed.

`bun run build`, `bun run start`, and `bun run typecheck` also forward to the website. See [the website README](../docs-site/README.md) for configuration and content editing.
