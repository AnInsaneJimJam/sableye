## Scope

`src/app/page.tsx`, the Sableye marketing home page. Visitor mode: Persuade.

Audience: the developer or technical founder at a small business choosing how to
accept USDT. Secondary and time-boxed: ETHGlobal Mumbai judges watching a 2 to 4
minute video. Job: decide whether this money path is safe, and get the integration.
Action: copy the real install command and the real snippet, and watch an invoice
settle. Proof on hand: the 20 line snippet, the contract's zero balance, 23 passing
Foundry tests, the three paths of the capability ladder, the measured finality lag.
Constraint: nothing is deployed, so every settled figure on the page is a labeled
simulation. No customers, logos, prices or benchmarks exist to show.

## Direction contract

THESIS: The page is one clearing-house settlement sheet, and the product's claim is
legible in the sheet's own columns: the merchant's payout column rises, and the
processor's balance column stays 0.00 on every row. It refuses the category's split
hero of copy beside a code panel, and refuses the row of equal icon cards below it.

OWN-WORLD: A pale blue-grey ledger stock under hairline rules that run the full
page height and do the layout work. One ink blue-black for every mark, a saturated
settlement green reserved for credited values, a vermilion reserved for reversals
and revocations. Archivo throughout, caps and tight tracking for column heads,
tabular lining figures everywhere a number appears. Geist Mono only inside real
code. No cards: a block is a span of ruled columns, and rank is how many columns it
occupies. Light ground, forced by the scene: a bright convention hall and a
compressed video, where near-black crushes and bands.

STORY: The visitor understands that an invoice is a signature, not a transfer. They
believe the money cannot be held, because the balance column proves it on every
row. They copy the install command and the snippet.

FIRST VIEWPORT: One sheet. The headline sits top-left across seven of twelve
columns at display scale, with no label above it. Beneath it, edge to edge, a single
settlement row at the largest scale on the page: columns ORDER, AMOUNT, PAYER, GAS,
PROCESSOR BALANCE, STATE. The amount is editable and set in huge tabular figures.
The STATE cell snaps through OPEN, SIGNED, PAID, FINAL. The PROCESSOR BALANCE cell
holds 0.00 throughout and is the row's quiet argument. A plain line under the row states that the settlement is
simulated because nothing is deployed yet.

ADAPTATION (primary action): the install command does not sit inside the row's
right-hand cell, as this block first said. That cell holds the control that runs
the settlement, which is the demonstration. Putting the conversion action in the
same cell made two primary actions compete inside one viewport. The install
command now sits in its own band directly beneath the row, under a START HERE
head, and returns at the foot on the total line. The row's own control stepped
down to a ruled cell action so the install cell is unambiguously primary.

ADAPTATION (columns): the row reads INVOICE AMOUNT, PAYER PAYS IN GAS, SABLEYE
HOLDS, YOU RECEIVE, STATE. ORDER and PAYER are dropped and YOU RECEIVE is added,
because THESIS requires the merchant's payout column to rise and the first column
list never carried one.

ADAPTATION (theme): a dark palette ships alongside the light one, because the
scaffold's theme toggle predates this surface. Light stays the default, so the
scene this direction was chosen for is unchanged.

FORM: The clearing-house settlement sheet, candidate 6 of 7 on my ordered grounded
list. seed:4f27c82bb75dc49a

RAISE (from the depot destination blind): nothing glides. Every changing value snaps
one row, overshoots once, and settles. State is a mark, never a hue alone.

RAISE (from the brick instruction booklet): the 20 lines are taught as numbered
steps where prior lines ghost and the step's new lines brighten, and one module
rules every alignment on the page.

RAISE (from the film cutting bench): rank comes from how many grid cells a block
occupies, not from type size.

RAISE (from the botanical folio): the three paths of the capability ladder are drawn
at identical scale on identical ground, so only their cells differ.

RAISE (from the silk colour chords): every state carries its name in text, never
colour alone.

RAISE (from the Googie starburst): one dominant focal move owns the first viewport,
rather than evenly weighted sections.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
