# Documentation reference artwork

These assets are local, unmodified copies of the illustrations used by the
[Mintlify documentation](https://www.mintlify.com/docs), the visual reference
requested for this project. Artwork attribution: Mintlify.

Source directory: https://github.com/mintlify/docs/tree/main/images/hero

- `rocket.png` / `rocket-dark.png`: Quickstart card.
- `cli.png` / `cli-dark.png`: CLI installation card.
- `editor.png` / `editor-dark.png`: the paired editor figures.
- `components.png` / `components-dark.png`: the exploded component figure.
- `background-light.svg` / `background-dark.svg`: complete decorative background.

The PNGs include the reference's dashed grid, colors, and rounded corners.
The SVGs include its original placement, shading, and fading mask. Both theme
variants are served locally under `/docs/illustrations/`; there are no runtime
requests to Mintlify or GitHub.
